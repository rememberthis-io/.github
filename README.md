# Remember This

[remember-this.io](https://remember-this.io) is the knowledge base for your life. Store written notes, documents, 
voice notes, and more all in one central place. Recall them later by asking Remember 
This. No configuration, organizing folder structures, or markdown files. Just a chat 
that memorizes and understands anything you give it.

There's many ways to use Remember This:

* Memorize and recall in [the web app](https://remember-this.io)
* Use memories as context for your AI agents
* Memorize and recall straight from any web page using the browser extension
* Forward Remember This your Telegram and Whatsapp messages

and more.

[Read the docs](https://remember-this.io/docs)
